十节课

HTML 可直接阅读。要跑 run.py、生成 report.md 的新结果，或保存 adapter，请 clone 后在本地执行。

01 · DATA

Datasets 管线

JSONL → Dataset → 切分、过滤、map。
02 · TOKENS

AutoTokenizer

input_ids、attention_mask，以及哪些 token 进入 loss。
03 · BATCH

Batch 与 Collator

padding 和 effective batch size。
04 · TRAINER

Trainer 闭环

用 tiny-gpt2 看最小训练循环和过拟合。
05 · LORA

手写 LoRA

冻结 base，看低秩矩阵 A/B 如何改变输出。
06 · PEFT

PEFT LoRA

真实 Hugging Face 模型上的 PEFT adapter。
07 · SFT

SFT baseline

客服工单 → 严格 JSON，对比训练前后。
08 · DPO

偏好优化

prompt / chosen / rejected 上的 preference loss。
09 · RLHF

Reward 概念

reward、reference、KL 和 PPO 信号。不是完整 RLHF 训练。
10 · QLORA

QLoRA 工程边界

量化、显存，以及 CUDA / bitsandbytes 与 Mac / MPS 的差别。
